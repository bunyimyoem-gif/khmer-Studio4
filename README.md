# Khmer Studio (Mobile & Dubbing)

កម្មវិធីលើវេប (PWA) សម្រាប់ស្តាប់ បកប្រែ និងបកសំឡេងខ្មែរតាមតួអង្គសម្រាប់វីដេអូ។

## របៀបដំណើរការលើ GitHub Pages
1. បង្កើត Repository ថ្មីលើ GitHub (ឧទាហរណ៍៖ `khmer-studio`)។
2. Upload ឯកសារ `index.html`, `manifest.webmanifest`, `sw.js`, និង `README.md` ចូលទៅក្នុង Repository។
3. ចូលទៅ **Settings -> Pages** -> ត្រង់ **Branch** ជ្រើស `main` (ឬ `master`) និង `/ (root)` រួចចុច **Save**។
4. រង់ចាំប្រមាណ ១–២ នាទី រួចបើក Link: `https://<username>.github.io/<repo-name>/`។

## របៀបដំឡើងជាកម្មវិធីលើទូរស័ព្ទ
- បើក Link GitHub Pages ក្នុង **Google Chrome** -> ចុចប៊ូតុង **📲 ដំឡើងជាកម្មវិធីលើទូរស័ព្ទ** ឬចុច **⋮ -> Add to Home screen**។

## ការបង្កើត MP4 តាម Server (ស្រេចចិត្ត)
ប្រសិនបើចង់ Render ចេញជាឯកសារ `.mp4` ដោយប្រើ `edge-tts` និង `ffmpeg` សូមដំណើរការ `dub_server.py` លើកុំព្យូទ័រ ឬ Cloud រួចដាក់ URL ក្នុងផ្ទាំង **🎨 រចនាអក្សរ & សំឡេងបក**។
